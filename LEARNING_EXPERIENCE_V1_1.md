# V1.1 — Full Learning-Experience Audit & Course Deepening

## Purpose

V1.0 established that Koinē Path had a complete, deterministic, production-safe 50-unit course. V1.1 asks a harder question: **does the Learn experience repeatedly train the mental actions required for independent New Testament Greek reading?**

The audit therefore evaluates learning function rather than raw content volume.

## Audit rubric

Each canonical unit was reviewed against the curriculum's intended loop:

**Orient → Observe → Explain → Recognize → Parse → Contrast → Read → Explain reasoning → Checkpoint → Review → Read again**

The v1.0 course already passed the following gates in every unit:

- clear objective;
- at least three teaching movements;
- worked forms/patterns;
- explicit interpretive safeguard;
- authentic Scripture-transfer task;
- exactly three deterministic mastery checkpoints.

### Cross-course v1.0 weaknesses

1. **Observation was implicit.** Learners usually received the explanation before being asked to notice a pattern.
2. **Contrast was underrepresented.** Confusable forms and minimal pairs were often described but not made into a dedicated learning step.
3. **Retrieval density was low.** Three mastery questions carried too much instructional responsibility.
4. **Reasoning was mostly receptive.** Learners selected answers more often than they articulated the clue used.
5. **Return-to-Scripture happened once.** The curriculum specifies a second pass after retrieval with reduced assistance.
6. **Practice and assessment were conflated.** Adding more scored questions would have inflated mastery instead of creating a safe place to struggle.

## V1.1 intervention

V1.1 preserves the 150 canonical mastery checkpoints and adds a separate, deterministic **unscored learning-experience layer**:

- 50 unit-specific reading-problem orientations;
- 50 controlled observation tasks (Greek-form/text observations in language units; an explicit edition-reference observation in Unit 49 where the learning target is evidence-layer discipline);
- 50 explicit contrast/minimal-pair tasks;
- 100 supplementary retrieval questions;
- 50 explain-your-reasoning prompts;
- a mandatory read-again step tied to the unit's Scripture passage;
- progressive disclosure for explanations so the learner attempts before revealing;
- no supplementary-practice writes to canonical mastery evidence.

This brings the Learn workspace much closer to the original curriculum architecture without changing the mastery thresholds or pretending that activity equals competence.

## Mastery firewall

The v1.1 supplementary practice layer must never call `recordEvidence()` or otherwise increase canonical mastery. It is intentionally a rehearsal space.

Only the existing reviewed checkpoints continue to write mastery evidence. The additional practice layer may keep ephemeral in-session answer state solely to show feedback and allow reflection.

## Learning-experience certification target

V1.1 is considered structurally complete only when CI proves:

- exactly 50 enrichment records corresponding to Units 1–50;
- exactly 100 supplementary retrieval items;
- unique practice IDs;
- a controlled observation in every unit, normally Greek and explicitly edition-referential for Unit 49's textual-evidence lesson;
- a contrast task in every unit;
- a reasoning prompt in every unit;
- NFC-normalized Greek strings;
- no mechanical tense/aspect, article, or case slogans in normative answers;
- the Learn UI loads the enrichment before `course-ui.js`;
- supplementary practice is explicitly unscored and has no mastery-evidence path;
- the original 150 mastery checkpoints remain unchanged in role and count.

## Remaining claim boundary

V1.1 materially deepens practice density and pedagogical sequencing, but automated structural QA cannot prove learning efficacy in the psychometric sense. Real learner outcomes, instructor review, retention data, and independent scholarly review remain separate evidence categories.
