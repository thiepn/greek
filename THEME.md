# Koinē Path Visual Language — Critical Edition

## Direction
A modern critical-edition / manuscript-desk interface rather than a generic SaaS dashboard.

## Principles
- Greek text is the dominant visual object.
- Use rules, margins, and typographic hierarchy instead of floating cards.
- Warm paper background with near-black ink.
- Rubric red is the primary accent, echoing manuscript rubrication without imitating an antique parchment prop.
- Editorial serif typography carries Greek, headings, explanations, and reading material; UI labels remain compact sans-serif.
- Controls are rectangular and restrained, not pill-shaped.
- Navigation behaves like a scholarly index.
- Reading and parsing screens should feel closer to an annotated text edition than a productivity app.

## Palette
- Paper: `#F3EFE7`
- Sheet: `#FAF7F0`
- Ink: `#1F1D19`
- Muted ink: `#6D675F`
- Rule: `#CFC7BA`
- Rubric red: `#8F332D`
- Lapis support: `#314C5D`

## Interaction
Reveal information progressively. Use highlighting sparingly: selected Greek forms use a pale rubric wash; primary actions use solid ink or rubric red. Progress is shown through thin rules rather than chunky bars.
